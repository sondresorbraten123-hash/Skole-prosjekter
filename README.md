# Skole prosjekter

## [Første semester](./Første%20semester/)

### [Programmering](./Første%20semester/Programmering/)

I programmering begynte vi med veldig basic python, hovedsakelig var det bare å lære syntaks og konsepter som løkker og if setninger, samt basic kobling til fil.

### [Webutvikling](./Første%20semester/Webutvikling/)

I webutvikling utviklet vi en statisk nettside for ett firma, nettsiden er laget med ren html og css. Så her er det ikke noe spesielt kompliserte ting.

## [Andre semester](./Andre%20semester/)

### [Programmering 2](./Andre%20semester/Programmering%202/)

I programmering 2 brukte vi fortsatt python, men det begynte å bli mer komplekse konsepter, her begynte vi med kobling mot database og GUI programmering. Vi begynte også såvidt med klasser, men dette var ikke en del av prosjektene jeg har her.

### [Systemutvikling](./Andre%20semester/Systemutvikling/)

I systemutvikling startet vi et prosjekt som skulle dekke litt mer, det største punktet i dette prosjektet var rapporten, selve nettsiden var egentlig bare ett valgfritt pluss. Vi gikk gjennom hvordan man skal gå frem for å utvikle store prosjekter.
